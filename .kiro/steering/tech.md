# Technical Stack
- **Language**: Python 3.9+
- **Agent Framework**: LangGraph (for orchestration and state management)
- **Workflow Engine**: Hatchet (for durable execution and background tasks)
- **Database**: PostgreSQL (primary), Redis (caching)
- **Frontend**: React/Next.js (target), currently Flask + Streamlit
- **Browser Automation**: Playwright
- **Legacy Components**: Flask, Streamlit, File-based logs
