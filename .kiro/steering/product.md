# Product Context
- **Name**: BettaFish (微舆)
- **Goal**: Multi-agent public opinion analysis system combining web search, social media monitoring, and private data mining.
- **Current State**: Transitioning from a legacy file-based agent system to a modern stack.
- **Key Features**:
  - International data integration (Google, Twitter, Reddit)
  - Real-time active monitoring with Hatchet
  - Collaborative agent workflows via LangGraph
  - Consolidated research reports
