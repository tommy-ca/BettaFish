# Task Generator Template

## Task Generation Process
1. Analyze design components and flows.
2. Break down into parallel implementation tracks (e.g., Backend, Frontend, Infra).
3. Create atomic tasks (max 1-2 days effort).
4. Order tasks by dependency.

## Output Format
- Use Markdown list with checkboxes: `- [ ] Task Title`
- Group by component or phase.
- Tag tasks with complexity [S/M/L].
